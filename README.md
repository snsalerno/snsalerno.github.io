# Portfolio personal

Versión 0.1 de un portfolio web académico.

## Archivos
- `index.html`: estructura y contenido.
- `css/estilos.css`: presentación visual.
- `bitacora_ia.md`: registro del uso de inteligencia artificial.

## Cómo probarlo
Abrí `index.html` en un navegador. Para publicarlo, subí el contenido del proyecto a un repositorio de GitHub y activá GitHub Pages desde Settings > Pages.

## Antes de publicar
Reemplazá `[Tu nombre]` y el correo de ejemplo. Revisá las descripciones de los proyectos, agregá evidencias reales y no publiques datos privados.
