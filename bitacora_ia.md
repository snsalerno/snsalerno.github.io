# Bitácora de inteligencia artificial

## Consulta 1
- **Fecha:** 07/11/2026
- **Herramienta utilizada:** ChatGPT
- **Objetivo:** organizar la estructura semántica de un portfolio personal.
- **Prompt completo:** “Necesito una estructura semántica para un portfolio con encabezado, navegación, presentación, sobre mí, proyectos, habilidades, contacto y pie de página. Usá solamente HTML5 y explicá la función de las etiquetas”.
- **Parte utilizada:** estructura general con `header`, `nav`, `main`, `section`, `article` y `footer`.
- **Cambios realizados por mí:** completaré el nombre, revisaré las descripciones de los proyectos y agregaré evidencias propias.
- **¿Qué comprendí?:** HTML organiza el contenido y las etiquetas semánticas indican la función de cada parte.
- **¿Qué descarté y por qué?:** datos personales innecesarios y contenido que no puedo comprobar.

## Consulta 2
- **Fecha:** 07/11/2026
- **Herramienta utilizada:** ChatGPT
- **Objetivo:** crear un diseño CSS inicial, adaptable a celulares.
- **Prompt completo:** “Creá un CSS inicial para un portfolio estudiantil con colores azul oscuro, azul y fondo claro. Usá CSS puro, tarjetas, espaciados y una adaptación para pantallas pequeñas. Explicá los bloques”.
- **Parte utilizada:** variables CSS, tarjetas, distribución con Grid y regla `@media`.
- **Cambios realizados por mí:** podré modificar colores, textos y tamaños para que coincidan con mi planificación.
- **¿Qué comprendí?:** las variables permiten reutilizar colores; Grid distribuye tarjetas y `@media` adapta el diseño a pantallas pequeñas.
- **¿Qué descarté y por qué?:** frameworks y animaciones porque no son necesarios para esta primera versión.

## Reflexión
La IA me ayudó a empezar y a resolver dudas, pero tengo que revisar el código, probarlo y poder explicar cada parte. La versión publicada debe incluir mis datos correctos y trabajos reales.
